hatebreed — Gothic capitals trial, version 7.000

INSTALL: Double-click hatebreed.ttf and select Install. The family name is hatebreed. This version combines angular custom Gothic uppercase letters with actual Proclamate Heavy lowercase outlines. The angular S from the approved reference is preserved. Curved flames and black silhouettes surround the transparent letter faces. A plain solid companion without flames is included.

Open hatebreed-try-it.html to type offline. Preview PNGs are rendered with the exported font. Earlier versions remain in their own folders.

129 characters, including ASCII uppercase, lowercase, numbers and punctuation, plus selected European characters. Some accented lowercase and symbols missing from Proclamate use earlier fallback outlines.
